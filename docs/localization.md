# 汉化范围与验证

## 已覆盖的主要终端区域

| 区域 | 本版内容 |
| --- | --- |
| 工具调用 | 读取、撰写、修改、执行命令、查找文件、搜索内容、列出目录；展开提示、超时和截断说明 |
| 启动 | 简派标识、快捷键说明、资源分组、无可用模型提示 |
| 设置 | 内置设置名称、描述、布尔值和常用枚举的中文显示 |
| 模型 | 模型选择、刷新提示、默认模型标记、思考强度和模型范围 |
| 登录 | 登录方式、服务商选择、凭据保存 / 移除反馈、登录框通用提示 |
| 会话 | 会话信息、恢复 / 分支 / 复制 / 导入 / 导出提示、会话树、书签操作 |
| 项目信任 | 初始询问、信任范围、保存状态和错误 |
| 工作状态 | 思考、重试、压缩、分支摘要、取消和常见错误提示 |
| 输入编辑 | 长粘贴折叠标记和隐藏行数；保留提交时恢复原文的行为 |
| 命令帮助 | `/` 命令说明、`/hotkeys`、CLI 帮助和软件包命令帮助 |
| 软件包 | 安装、移除、刷新、更新进度与常见诊断 |
| 主题 | 主题设置、加载失败和主题格式诊断 |

精确文件与条目数量以本次 `npm run build` 的输出和 `build/translation-report.json` 为准。条目数量不是百分比覆盖率。

## 简短命令说明

按用户实际反馈，Bash 工具调用标题在开头的裸 `ls`、`rg` 后显示 `（列出文件）`、`（搜索内容）`。仅添加显示说明，不修改真实参数、执行模块或原始输出，不适用于 PowerShell。组合命令只处理开头，包装命令、绝对路径、引号中的命令和脚本正文不处理；不会全文替换。通用用途不代表选项分析、别名识别或安全判断。

新增 2 项源码 / 内存编译渲染测试已通过；当前运行构建未更新，完整构建检查及重启体验仍在 `TODO.md` 待办。

## 明确保留原文

- 工具参数名称、命令、路径、代码、代码差异、协议字段。
- 命令原始输出与原始工具结果；例如 `ENOENT` 和编译器日志。
- 模型 / 服务商名称、第三方自定义设置和主题名称。
- AI 回复正文：界面汉化不靠篡改回复实现。
- 上游技术文档、历史更新日志、许可证。

## 尚未覆盖 / 未完全验证

- 第三方扩展自行渲染的文字，以及服务商返回的动态 OAuth 提示和底层异常原文。
- 实验性远程服务、部分底层诊断，以及 HTML 导出页面的内置界面文字。
- 全部真实模型服务商的登录流程、付费请求、所有第三方扩展组合。
- Windows / Linux 的实际交互及中文输入法候选框位置；本次在 macOS 验证。

因此当前称为“首版中文构建”，不宣称所有 Pi 字符串都已 100% 汉化。后续发现遗漏仍归入第一阶段补齐，不以解释功能替代汉化。

## 已做验证

- `npm run build`：从固定版本生成独立中文构建。
- `npm run check`：语法、指纹和生成文件一致性；执行 / 会话 / 凭据核心模块保持原样。
- `npm test`：14 项无付费 API 的自动测试，包括真实文件读写与修改、终端命令、失败、取消，以及中文粘贴标记的展开和删除。
- 中文工具标题、长日志展开、原始日志与 AI 正文不被误翻译。
- 设置显示中文时，回调仍返回原始布尔值和英文枚举。
- 24 / 40 / 80 / 120 列下的代表性组件宽度检查。
- 独立终端中启动并实际打开设置和登录菜单；不修改用户原有 Pi 配置。

## 发现遗漏时

记录：所在界面、原文、出现步骤、期望译文。先判断是否属于程序文案，还是命令 / 代码 / 外部原始输出。

`npm run audit:zh` 会生成 `.local/english-review.md` 帮助人工复核。它只扫描已纳入汉化的文件，并会包含合法英文标识；不是“全项目已无英文”的证明。
